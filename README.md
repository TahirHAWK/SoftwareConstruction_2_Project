# Sheep GUI Project

This is a Java-based graphical user interface (GUI) project that allows users to create and interact with sheep of different colors and sizes. The application uses buttons to control the color and size of randomly generated sheep on the screen.

## Features

- **Add Sheep:** Create random sheep with a variety of colors.
- **Change Sheep Color:** 
  - **Green Button:** Changes the color of all sheep to green.
  - **Black Button:** Changes the color of all sheep to black.
  - **Grey Button:** Changes the color of all sheep to grey.
- **Change Sheep Size:**
  - **Small Button:** Reduces the size of all sheep to small.
  - **Large Button:** Increases the size of all sheep to large.
